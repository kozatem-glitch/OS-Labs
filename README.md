# Лабораторная работа №1: Конвейер процессов.
## Реализация конвейера из трёх процессов, взаимодействующих через неименованные каналы (pipes).

### Структура:

- Parent - читает строки произвольной длины со стандартного ввода (`stdin`), передаёт их в `pipe1` дочернему процессу `Child 1`, затем забирает результат из `pipe3` и выводит на экран.
- Child 1 - переводит все символы в верхний регистр.
- Child 2 - удаляет задвоенные пробельные символы (пробелы, табуляции, переносы строк и каретки), оставляя только один.
- Makefile - правила сборки.

### Что используется

- Системные вызовы POSIX: `fork`, `pipe`, `dup2`, `execv`, `read`, `write`, `close`, `wait`
- Перенаправление стандартных потоков (`stdin`, `stdout`) через `dup2`
- Запуск дочерних программ как отдельных исполняемых файлов через `execl`
- Сборка через `Makefile`

### Сборка и запуск

Для компиляции всех программ выполните make
```bash
make
```

Запустите родительский процесс
```bash
./parent
```
или
```bash
make run
```

Введите строки в терминале. Чтобы завершить ввод и получить результат, нажмите Ctrl+D.

Удалить скомпилированные программы
```bash
make clean
```

Справка
```bash
make help
```
